Tentang Saya

Perkenalkan, saya Raffi Hazizi, lulusan D3 Teknik Komputer dari Politeknik Negeri Padang dengan IPK 3,36. Saya memiliki pengalaman dalam bidang IT Support, administrasi jaringan, dan pengelolaan server.

Saya memiliki kompetensi dalam instalasi, konfigurasi, dan pemeliharaan jaringan LAN, pengelolaan perangkat router dan switch, serta troubleshooting perangkat keras maupun perangkat lunak.

Selain itu, saya memiliki pengalaman dalam pengelolaan server berbasis Linux, layanan FTP/SFTP, mail server, VPN, backup data, serta dokumentasi dan pemeliharaan infrastruktur IT.

Saya merupakan pribadi yang senang mempelajari teknologi baru, memiliki kemampuan analisis masalah, serta berusaha menyelesaikan pekerjaan secara sistematis dan bertanggung jawab.
